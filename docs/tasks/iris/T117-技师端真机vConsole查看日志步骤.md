# T117 技师端小程序真机查看日志步骤（给硬件测试人员）

> 适用对象：硬件方测试人员（非开发者、非小程序管理员）。
> 场景：真机测试技师端小程序时，想自己看日志（配网过程、BLE 写入等）。

## 真机上打开 vConsole 的步骤（5 步）

1. 打开技师端小程序（开发版或体验版都行，正式版没有「打开调试」入口）。
2. 点小程序右上角的「···」（三个点）。
3. 在弹出来的菜单里点「打开调试」，小程序会自动退出。
4. 把小程序从后台彻底关掉，再重新打开，屏幕右下角会出现一个绿色的「vConsole」小按钮。
5. 点「vConsole」按钮就能看日志了（带 `[BLE]` 开头的就是配网过程），看完点右上角的 X 关闭。

## 如果看不到「打开调试」入口

「打开调试」这个入口只有开发者/管理员才能看到。如果点「···」后菜单里没有这一项，说明这台手机开不了 vConsole，**只能由 Boss 在 WeData（wedata.weixin.qq.com）实时日志里查看你的操作**。
